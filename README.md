# Bike Sales Excel Dashboard 📊

## Project Overview
This project is an interactive Excel dashboard created to analyze bike sales data and customer purchasing behavior.

The dashboard allows users to filter and explore the data dynamically using slicers and pivot charts.

---

## Tools & Features Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Interactive Dashboard Design
- Data Cleaning
- Data Categorization

---

## Dashboard Insights
The dashboard analyzes:

- Average income per purchase
- Customer age brackets
- Customer commute distance
- Marital status
- Education level
- Regional distribution
- Bike purchase behavior

---

## Interactive Features
Users can interact with the dashboard using slicers to dynamically filter the data by:

- Marital Status
- Education
- Region

Charts and visualizations automatically update based on selected filters.
